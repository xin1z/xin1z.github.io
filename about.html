About This Site

I started thinking about this site in winter 2025, when I was in Grade 8. All I knew was just some C++ and basic HTML, which was definitely not adequate to create a modern static website. So things had been stopped for about a year and a half until June 1st, 2026, as I started picking up some basic frontend knowledge using MDN's online tutorial.

On second glance, HTML and CSS felt much easier to learn. I quickly studied all the basic concepts needed and coded index.html and css/style.css in an afternoon. And that's basically how this site was created.

This site is still under development, and I'm not yet familiar enough with CSS. Hopefully, as my technique improves, this site will look better.
