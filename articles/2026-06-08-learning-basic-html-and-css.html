I learned basic HTML and CSS in a week, and that's how it feels

Jun 8 2026

Web, Web, Web—something that’s already been there for over 30 years.

It has even lived longer than some of us here.

As a teenager who loves computer science, learning HTML and CSS seems like a natural move for me.

And that’s how it started.

HTML

Basic structure

The basic structure of HTML seemed pretty straightforward at first, which was good.

A <head> and a <body> within a pair of <html>, and that’s basically it. <!DOCTYPE html> feels weird though, since it seems kind of unnecessary now. Tech debt has been here for a long time; what I could do was just accept it.

Semantic tags

Semantic tags sound attractive, but people just don’t use them that much (and that’s usually a sign of AI-generated code or just unrestrained use of UI frameworks), as somebody says, “well, it’s listed, and you decide whether to use it or not”.

I’m too naive to be disobedient, so semantic tags are needed. And they provide extra accessibility to the site, so why not?

Tags like <header> and <article> look good, and using them doesn’t waste you too much time.

Other stuff

Of course, there are other tags and syntaxes for HTML.

But as a regular person who’s not really good at memorizing things, I decided to search MDN’s Document or just google it when actually needing the knowledge.

Well, not bad.

CSS

Think of parts of an HTML document as objects, and that’s it

See pairs like <foo></foo> ? Select it using:

foo {
    ...
}

Or, add it to certain class(es) using <foo class="class-name"></foo> and select it:

.class-name {
    ...
}

Maybe even give it an ID using <foo id="an-id"></foo>, and select it:

#an-id {
    ...
}

That’s basically it.

Properties? Too Many of them

As a kid who knows no more than 26 English letters and maybe 4000 Chinese characters, my brain doesn’t allow me to memorize all properties applicable to an HTML object. So again, just google it.

Auto-completion helps a lot when writing CSS, too. AI? Not recommended, at least think it yourself first, or I just don’t see the difference between using AI to do everything and giving your brain a lobotomy surgery.

Good structure? Learn it in practice

Read the code first, and you’ll know what’s next.

See? Thousands of websites are already there. Just right-click the page and select Inspect Element. That’s how I learn the structure.

A good documentary also helps. I’ve been using MDN’s online document for quite a long time, and it’s been working well.

Where to go next?

Frankly speaking, I don’t know. Maybe try something else, or just put everything away a bit and have some ice cream. Who knows?
