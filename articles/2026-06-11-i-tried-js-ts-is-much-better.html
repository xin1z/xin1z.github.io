I tried JavaScript, TypeScript is much better

Jun 11 2026

Why JavaScript?

I've learned basic HTML and CSS lately, and JS is, of course, what I'm going to learn next.

JavaScript was created in 1995. DAMN, almost 15 years older than me. This also means tech debt is bound to be there, which adds extra difficulty to actually master it.

It's old, of course. WebAssembly has been introduced, which means I can actually use it (yay!), though it's still kind of new to most people, and JS is just everywhere. It thus has become my only option.

At the very start...

JS isn't a typed programming language, which isn't bad, since it was introduced in 1995 for Web Developers.

But bro, type is important, especially when you actually need it to figure out what's happening. You might've seen a lot of JS memes related to its weird dynamic type system. I'm not going to list them here. See WTFJS to actually experience it. And after trying it out a bit, I'd say it's just implementation magic.

Behaviors? If undefined, just let the interpreter do its job (this part is defined though). So, wow that's basically what a regular developer would want right?

No. If you're a web developer, you know how shitty it is. And as a naive teenager who loves programming, JS becomes a nightmare for me. I've never missed type so much, where the fxck are you?

Until I found TypeScript...

TypeScript. At least Microsoft did something good

TS has solved so many problems I've encountered while learning JS. Type changes everything bro.

The interpreter checks the type and translates the TS code into JS, which makes it compatible while staying typed. Magic? not anymore. Just let me code, tell me what's wrong. That's it.

Thank you Microsoft. At least you guys have done something good.

What else?

Well, it takes time to learn. I'm still learning JS, because there's only TypeScript for JavaScript developers. I'm just not allowed to quit JS that early.

But at least I've saved a bunch of time with TypeScript, which is good.

Learning to code takes time. I just need to do what's necessary (to study).
